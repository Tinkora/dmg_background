# Support

[简体中文](SUPPORT.zh-CN.md)

This Pre-release project is maintained on a best-effort basis by one
maintainer. There is no response-time or compatibility guarantee.

Public Issues and Discussions remain disabled until moderation and private
conduct-reporting capacity are ready. Before opening a pull request, use the
README, contract, product scope, and existing tests to confirm that the request
belongs to the implemented browser-local workflow.

Use private vulnerability reporting for security concerns. Do not send private
application artwork, signing credentials, or personal data through public
channels.
