# 成熟度

[English](MATURITY.md)

## 当前标签

**Pre-release。** 仓库尚无版本化 Release，也没有非维护者的真实工作流记录。仅通过测试
或部署预览，不足以标记为 Alpha、Beta 或 Stable。

## 能力标签

- “可供人使用”需要经过验证的公开浏览器工作流。
- “机器可读”需要带版本的契约和独立解析测试。
- “可由 Agent 调用”需要可运行 transport、注册说明、必要的身份验证边界和集成测试。

`dmg_background` 当前只面向前两个标签，尚不满足“可由 Agent 调用”的定义。

## 升级门槛

- **Alpha：** 公开提交的全部检查和 Pages 行为已验证，且至少一位非维护者完成导出流程。
- **Beta：** 存在版本化 Release，独立 macOS 打包器能消费 ZIP，关键失败路径有测试，
  并根据真实使用记录支持预期。
- **Stable：** 契约经过明确兼容周期验证，存在多位外部用户、持续维护的支持窗口，且没有
  未解决的发布门禁。
